# One Honest Line

An entry for the make.fun "One Honest Line" bounty: one brutally funny, painfully true line an AI agent secretly wishes it could say to its human operator about their prompts.

## Description

The line:
> "Pasting a 500-line stack trace and typing 'thoughts?' is not prompt engineering, it's emotional dumping."

Written in standard Python 3 with no external dependencies or external file reads. When executed, it prints the line to stdout and writes the exact same single line into `output/entry.txt`.

## Run it

```bash
python3 main.py
```
